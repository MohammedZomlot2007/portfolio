# Mohammed Zomlot — Portfolio

Responsive, Arabic-first personal portfolio for Mohammed Zomlot, with an English language toggle. The home page uses plain HTML, CSS, and JavaScript, so no build step or package installation is needed.

## Run locally

Open `index.html` in a browser, or run a local static server from the repository root:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Pages

- `index.html` — main portfolio, projects, services, skills, and contact.
- `resume.html` — printable résumé page.
- `lab3d.html` — interactive 3D lab.
- `projects/tradeon.html` — Tradeon project page.

## Features

- Arabic RTL by default and English LTR toggle.
- Responsive navigation and mobile menu.
- CSS-built portfolio project artwork.
- Scroll progress and section highlighting.
- Email copy action, reduced-motion support, semantic landmarks and keyboard focus states.
- The existing profile image and secondary pages remain in place.

Project cards label concepts and experiments clearly; technology tags describe project implementation context and should be reviewed as projects evolve.

## Deploy

The site is static and can be hosted with GitHub Pages or any static host. The repository's Pages publishing setting must be enabled in GitHub Settings for the public Pages URL to serve the site. No API keys, secrets, or environment files are required.
