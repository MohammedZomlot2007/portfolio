# Mohammed Zomlot — Developer Portfolio

Arabic-first responsive developer portfolio with an English language toggle, project filters, project detail dialog, scroll reveals, and mobile navigation.

## Local preview
This is a static site. No build step or environment variables are needed. Run `npx serve .` from this directory or open `index.html`.

## Deployment
Vercel serves this folder as a static site. Set the project Root Directory to `portfolio-redesign`; leave build and install commands empty.

## Structure
- `index.html`: semantic page content and sections
- `styles.css`: visual system, layouts, animation, and responsive breakpoints
- `script.js`: Arabic/English translations and UI interactions
- `assets/`: Jerusalem hero background, portrait cutout, and favicon

Project thumbnails are handcrafted CSS illustrations, not screenshots of live products. Labels show each project's current stage. Contact links use email and social profiles; no contact form backend is configured.
